# eRandevu - SaaS Randevu Yönetim Platformu

eRandevu, işletmeler için modern bir randevu ve müşteri yönetim sistemidir.

## Kurulum

1. `cd frontend && npm install`
2. `frontend/.env.example` dosyasını `frontend/.env.local` adıyla kopyalayın ve Firebase Console > Project Settings > Your apps > Web app bölümündeki değerleri yazın. `.env.local` depoya girmez.
3. `npm run dev`
